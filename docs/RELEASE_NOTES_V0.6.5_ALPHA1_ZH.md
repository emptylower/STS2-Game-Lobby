# STS2 LAN Connect v0.6.5-alpha.1 预览版发布说明

- 日期：2026-11-24
- 类型：GitHub Pre-release（预览测试版）；正式稳定版与 Steam 创意工坊当前仍为 `v0.6.4`。
- 客户端版本：`0.6.5-alpha.1`；`lobby-service` 保持 `0.6.3`（本次无服务端代码变更，无需升级大厅服务端）。
- 下载：本页面附件 `sts2_lan_connect-release.zip`（含 `SHA256SUMS`）。

## 更新内容

### 联机稳定性（P0）

- **修复多人续局／重开顺序依赖（逆序加入报 `ModMismatch`）**：
  - 通过 3 人同一份存档对照实机复现确认：正式版 `v0.6.4` 在续局／房管重开时，原生 `ClientLoadJoinResponseMessage` 玩家列表按当前重进到达顺序排列，与 Tail 扩展帧按存档槽位排列的名册顺序不一致，导致逆序后加入的客机触发 `ModMismatch` 断开；按首次入房顺序加入则侥幸通过。
  - 本版在发送 `LoadJoin` 响应副本前按存档实际槽位重排并保持玩家标志随身份对应，同时不修改大厅共享列表。
- **#48 同成员离开重进后开局**：
  - 细化 Tail 挂起扩展帧在 writer reset 时的清理日志（区分发送前清理 `cleared_before_any_transport` 与发送后常规清理 `cleared_after_transport`），快速重连时显式替换旧流状态，避免旧流干扰并补齐多轮离开重进回归测试。
- **#46 减员后立即开局**：
  - 引入认证原生离开通知与准备房名册更新，避免准备房成员离开后立即开局因名册不一致被拒；运行中掉线继续不套用准备房减员规则。
- **#44 游戏 0.113 容量构造兼容**：
  - 优先匹配 0.113 新版五参 `StartRunLobby` 构造函数并兼容回退旧版四参构造函数。

### 昵称与交互体验（P1）

- **选服页玩家昵称设置与敏感词拦截重试**：
  - 选择服务器弹窗新增「玩家名」输入框，连接大厅触发敏感词审核拒绝（`content_blocked`）时保持弹窗打开、展示提示并自动聚焦全选旧昵称以便直接修改重试；同步修复大厅设置面板等带字数计数输入框在程序赋值后计数器未刷新的问题。
- **#32 游戏按钮与原生弹窗下按 `Enter` 不再误开房间聊天**：
  - 焦点位于聊天面板外部可交互控件时放行 `Enter`；补齐对游戏原生弹窗容器 `NModalContainer.Instance?.OpenModal` 的检测，防止原生提示／确认弹窗打开时按 `Enter` 弹出房间聊天。`F8` 快捷键仍可随时开关聊天。
- **#49 房间聊天浮层遮挡与触摸拖动修复**：
  - 收敛聊天外层透明容器的 `MouseFilter` 为 `Ignore`，修复聊天收起态在屏幕右上角吞掉游戏设置齿轮点击的问题，并修复单指触摸长按拖动的事件初始化时序。
- **#40 自定义模式邀请按钮补齐**：
  - 为自定义模式建房页（`NCustomRunScreen`）与自定义续局页（`NCustomRunLoadScreen`）补齐邀请按钮挂接，与标准模式保持一致。
- **#51 新建房间默认优先选择「新协议」**：
  - 新建房间默认选中可用的「新协议」（301），并将「新协议」置于选项首位；新协议不可用时自动回退「兼容旧版 Mod」（300），保留手动切换。
  - 当两种协议均不可用时（例如已安装 RitsuLib 且游戏版本缺少 `0.111+` 原生通道或存在 RMP 冲突），明确列出双方不可用原因并禁用「发布房间」按钮，不再静默回退。
  - 已有续局存档与加入房间仍严格遵守原存档／房间已冻结的协议，不会因新建房间默认值变化而静默迁移旧存档协议。

### 明确不适配与后移项

- `#43` 东尼算法明确不适配，不纳入本轮及后续兼容范围。
- `#45` 结算页新开一局、`#47` 跨服房间池按计划后移。

## 验证结果

### macOS `arm64` 实机验证（游戏 `v0.113.1` · `--force-steam=off` · 本地 `lobby-service 0.6.3`）

- **3 人同一份存档重开对照矩阵**（槽位 `[Host3P, PlayerA, PlayerB]`，新协议 `tail_v1`）：
  - 正式版 `v0.6.4` 手动读档 + 逆序 `[B, A]`：必现复现 PlayerA 被踢并报 `ModMismatch`；
  - 正式版 `v0.6.4` 同一局改为原序 `[A, B]`：全部进入成功；
  - 本版候选通过房管面板「重开一局」自动重连（实测 B 先连、A 后连，逆序 `[B, A]`）：`rev=1 (B)`、`rev=2 (A)` 均正常通过，3 人恢复至第 1 层战斗原槽位。
- **#48 双人实机（8 人新协议房）**：房主就绪 → 客机离开 → 同客机重进 → 客机就绪立刻开局，双端正常进入第 1 阶段；日志严格按 `rev=1 → departure (currentRev=1) → rev=2 → LobbyBeginRun (rev=3)` 推进，0 次发送前清理、0 次 revision gap。
- **昵称审核、#32、#49 实机**：验证了敏感词 `content_blocked` 拦截后弹窗保留与焦点回选重试、原生弹窗打开时按 `Enter` 不再误开聊天、局内聊天收起态直接点击右上角设置齿轮打开暂停菜单以及 `F8` 开关固定。

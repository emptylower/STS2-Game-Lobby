游戏大厅 0.5.6-rc1 测试候选已准备好。

本次集中修复四组现场问题：内容 MOD 改变 ModelId 线上编码后仍错误放行，导致等待页卡住或黑屏；续局绑定被误写/删除，导致回主菜单和房主重开后房间无法重新发布；槽位接管后踢人会误封原主人；踢出通知可能发给错误连接。

客户端现在使用 WireCacheSignatureV1 在 lobby-service 签发 ticket 前和游戏握手发出 join request 前比较线上编码。真实不一致会明确拒绝；签名缺失或读取失败仍允许加入。默认兼容配置也已恢复为 strict。

这是测试候选，不是正式版。客户端和 lobby-service 请成对升级到 0.5.6-rc1。两台机器的内容 MOD 不同并改变线上编码时，拒绝加入是预期行为。

遇到加入失败、黑屏或等待页卡住，请同时提交两台机器的完整 godot.log。本版会打印签名、四个位宽、表条目数和每个 MOD 的 affects_gameplay 标记。下载地址与 SHA-256 校验值以 GitHub Release v0.5.6-rc1 页面为准。

游戏大厅 0.6.0 正式版已发布。

这是 0.5.5 之后的第一个正式版，收敛了 0.5.6-rc1~rc4 与 0.6.0-alpha.1~alpha.9 全部九个测试候选。客户端与 lobby-service 版本号同步定为 0.6.0。

本版最重要的修复是「安装/更新 MOD 后主页看不到联机大厅」。根因是 MOD 加载顺序竞态：RitsuLib 先初始化时，它声明在泛型类型上的补丁方法会毒化闭合泛型目标，本 MOD 的协议补丁随之抛 InvalidProgramException，初始化中止，大厅 UI 从未安装。现在 Tail 补丁全平台默认使用 15 步非泛型计划，不再注册任何闭合泛型目标，线上字节格式零变化。任意加载顺序下大厅都会正常出现，旧版「先关 RitsuLib、启动一次、再开 RitsuLib」的临时办法不再需要。

如果协议补丁仍然失败，MOD 不再整体失效，而是进入降级模式：大厅照常可以浏览，建房/加入会被拒绝，并弹出游戏原生提示说明原因和恢复方法。

其他主要改动：房主端不再把客机显示为数字平台 ID；自动 SL 后「重开一局」客机会自动返回并按原存档槽位重连；SL/读档续局不再丢失协议身份；「放弃多人存档」弹窗按钮不再被裁切；开局加载较慢时服务端不会再误删仍活跃的中继。加入前会比较双方真实的 ModelId 线上编码，内容 MOD 不一致时在黑屏前明确拒绝——这是预期行为。

升级要求：同一房间所有玩家必须统一使用客户端 0.6.0，安装或更新后完整重启游戏。使用 RitsuLib 的玩家请统一安装官方 v0.5.13 及以上。服主建议升级到 lobby-service 0.6.0（与 0.6.0-alpha.6 功能相同，只对齐版本号）；已开启自动更新的节点会自动升级。

本轮通过 GitHub Release 分发，Steam 创意工坊暂不上传，创意工坊条目仍停留在 alpha.7。下载地址与 SHA-256 校验值以 GitHub Release v0.6.0 页面为准。

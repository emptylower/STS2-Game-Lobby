# STS2 LAN Connect v0.5.4 客户端候选发布说明

> 状态：客户端清单、程序集和构建版本已更新为 `0.5.4`，GitHub Release 与 Steam Workshop 更新暂未发布。

## 新增审核交互

- 聊天首次进入服务端 AI 审核时，消息不会提前出现在公共聊天栏；输入框上方显示紧凑的“在审核中”状态。
- 审核通过后沿用原 ACK 与广播流程，原文静默出现，不再额外弹出成功提示。
- 审核拒绝时移除本地待审消息，并使用游戏原生面板显示“包含违禁词，请稍后再试”。
- 同一连接已有待审消息时，本地发送门禁与服务端 `moderation_busy` 共同避免重复审核。
- 收到 `chat_messages_redacted` 或 `room_chat_messages_redacted` 时，客户端按消息 ID 幂等删除服务端指定的拆字上下文；房间帧必须匹配当前 `roomId + roomSessionId`。
- 房间名、用户名或续局角色名审核失败时，创建/加入流程使用游戏原生敏感词提示，不显示原始 HTTP 错误。

## 状态与恢复

- 客户端投递状态扩展为 `Pending → Reviewing → Confirmed/移除`。
- 审核超时只进入投递未知状态，不会误标发送成功；断线、切换频道、切换房间或退出时清理审核状态。
- 相同 `clientMessageId + 相同内容` 可安全复用待审状态；相同 ID 不同内容仍按重复消息错误处理。
- AI 故障下服务端普通打码 ACK 仍按普通成功消息展示，故障详情不会暴露给玩家。

## 兼容性

- 新帧在通用版本检查前按宽容规则解析；未来版本或未知帧不会仅因无法识别而断开连接。
- 旧客户端可以继续连接 `0.5.4` 服务端并接收最终结果，但不能删除已经显示的跨消息违规上下文。
- 旧版 `room_chat`、富聊天引用、MOD 预检、LAN/大厅续局通道及存档保护行为保持不变。
- 游戏加载目标继续为 `0.107.1`、`0.109.0` 与 `0.109.1`。

## 安装与验收

1. 完整退出游戏。
2. 使用 `0.5.4` 构建产物覆盖安装完整 `sts2_lan_connect` 目录，不能混用旧 DLL、PCK 或 manifest。
3. 重新启动游戏，确认模组清单显示 `0.5.4`。
4. 分别验证单条审核通过、审核拒绝、审核超时、拆字撤回、房间名拒绝和用户名拒绝。

本文件仅作为候选构建说明；正式下载链接、校验值和发布日将在创建 GitHub Release 时补充。

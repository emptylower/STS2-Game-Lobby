# STS2 LAN Connect v0.6.4 发布说明

- 日期：2026-11-15
- 客户端版本：`0.6.4`；lobby-service 保持 `0.6.3`。
- 分发：更新远程仓库源码、版本标签与 `releases/` 客户端安装包。本次未创建 GitHub Release，也未推送 Steam 创意工坊；这两个渠道最近一次发布仍为 `0.6.3`。
- 下载：[客户端安装包](https://github.com/emptylower/STS2-Game-Lobby/blob/main/releases/sts2_lan_connect-release.zip)。

## 游戏 0.113.0 兼容

适配 0.113 的游戏接口与消息布局变化，同时保留旧版运行时兼容路径：

- **加入房间**：接管引用已删除字段的旧加入流程，复用游戏 JoinFlow，并兼容加入结果及进阶解锁字段的新旧形状。
- **极速／恐惧准备页**：加入这两种房间时推送对应原生准备页，避免被旧的模式分支当作未知模式而报 InternalError。
- **桌面房主加入响应**：按 0.113 布局补齐 `gameMode`、`isCustom`；旧版没有这些字段时仍写旧布局，避免后续字段错位。
- **新协议拒绝与中止**：兼容 `DisconnectClient` 参数及 `ConnectedPeers` 集合返回类型变化。
- **放弃本局与难度缩放**：适配进度更新返回值、缩放模型位置及运行状态访问方式。
- **宝物室投票**：0.113 的跳过票走游戏原生实现，旧版保持相应兼容分支。

兼容旧版是同一份 MOD 对新旧游戏接口的适配，不能让不同游戏版本的玩家互联，游戏版本匹配检查继续生效。

## 模式、中文与手机聊天

- 大厅和 LAN 建房支持选择游戏已解锁的极速／恐惧模式，房间卡片及详情标出对应模式。
- 沿用原生解锁条件，不强制解锁模式，不修改进度存档。
- 大厅、服务器选择页、房间聊天、管理面板和独立对话框补齐中文字体回退；复用游戏字体，不随包分发游戏字体文件。
- 手机点按聊天中分享的卡牌名称可打开固定预览；触摸释放与模拟鼠标激活去重，普通悬停结束保留固定预览。
- 预览创建失败时显示可关闭的友好提示；引用渲染、激活、显示和关闭增加限量诊断，不记录聊天正文或异常消息。

本次未新增第三方兼容补丁中的结算页新开一局等功能。原有房间管理重开与续局保护继续保留。

## 升级方法

1. 建议同房玩家统一更新到客户端 `0.6.4`，并确认游戏版本相同。
2. 替换完整的 `sts2_lan_connect` MOD，完全退出后重新启动游戏；仅替换运行中的文件不会热更新代码。
3. 游戏 `0.113.0` 玩家应更新本版。现有 lobby-service `0.6.2` 及以上无需为本次客户端修复升级；服务端包和版本本次保持不变。

线上协议版本、tail 房间 `minimumClientVersion` 保持不变。更新前仍建议保留游戏存档与 `user://sts2_lan_connect/` 的有效备份。

## 验证与范围

发布验证期间，Steam 将本机游戏自动更新至 `0.113.1`（提交 `d09d48e5`）。原 `0.113.0`（提交 `16ac0fe3`）程序集已保留，便于分别检查新旧接口与报文。用户的手机复测反馈仍对应 `0.113.0`，不视为 `0.113.1` 手机实机验收。

正式 `0.6.4` 安装包已完成以下检查；主测试集编译及运行使用本机 `0.113.1`。三个游戏版本的接口与报文检查分别在独立进程中加载同一份最终交付 DLL。测试工程编译保留既有生成器／分析器等警告，与生产安装包构建的 0 警告分开记录。

| 主单元测试 | 1352 项通过、1 项既有跳过、0 失败 |

`0.113.1` 与保留的 `0.113.0` 的 MOD 元数据字段形状一致；回归测试补充锁定 `0.113.1` 的已知契约，没有以宽泛放行绕过未知版本检查，也未因此修改生产运行时逻辑。接口检查仅覆盖程序集类型加载及直接成员引用，不证明所有反射与 JIT 执行路径。原生编解码检查使用空玩家／修饰列表隔离消息体布局，不能替代非空 roster、消息总线、传输或完整多人实测。

- Godot 探针通过 `Input.ParseInputEvent` 驱动真实生产消息控件与预览控制器，未直接发射点击信号；视觉／原生端口使用替身，但 Ready 与节点释放走真实 Godot 生命周期。探针加载的生产 DLL 与最终安装包哈希相同。独立探针构建有 1 条既有 `GodotPlugins.Main` 类型冲突警告，运行没有 Godot ERROR／WARNING；这些结果不代表真实 Android 卡牌资源的全面验收。
- 中文显示由用户确认服务器选择页和房间聊天等处正常；2026-11-15 用户在第三轮诊断包后反馈“没问题了”，记录为手机端复测通过。该反馈没有附带新的诊断日志，不能据此将某个单一根因认定为已由日志证明，也不扩展为所有 Android 设备验收。
- 本机真实旧版程序集检查覆盖 `0.111.0`；未完成真实 `0.107` 验证，未在本轮逐一重测所有续局、重连、第三方 MOD 组合或完整双客户端流程。
- 此前发布记录中的严重丢包断线、候选切换短暂误报 `ModMismatch` 等网络问题仍未在本次修复。

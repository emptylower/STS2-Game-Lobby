# STS2 LAN Connect v0.5.3 客户端正式发布说明

> 这是客户端 `0.5.3` 的正式发布，客户端包作为附件发布在 GitHub Release [`v0.5.3`](https://github.com/emptylower/STS2-Game-Lobby/releases/tag/v0.5.3)（与 lobby-service 0.5.3 同一 Release）。服务端的 0.5.3 发布说明见 [`RELEASE_NOTES_V0.5.3_ZH.md`](./RELEASE_NOTES_V0.5.3_ZH.md)。

v0.5.3 客户端的核心是 **LAN 与大厅续局通道拆分**（issue #40）：多人存档现在记住自己的创建入口，纯 LAN 存档续局不再被误发布到公共大厅；同时修复了 BaseLib 共存毁档、安卓加入页强制超时等问题，并完成局内聊天 HUD 化改造。聊天与加入线协议不变，与 lobby-service 0.5.1/0.5.2/0.5.3 及 v0.5.1+ 客户端均可互通，服主无需升级服务端。

## LAN 与大厅续局通道拆分

- 多人存档的本地绑定（`LanConnectSavedRoomBinding`）新增持久化字段 `HostChannel`，取值为 `lan` / `lobby`：纯 LAN 入口创建的存档写入 `lan`，大厅入口写入 `lobby`；客机加入、接受邀请、选槽不会写入或覆盖。
- 续局时自动发布器在大厅端点预检**之前**解析有效通道：通道为 `lan` 的存档跳过发布（日志 `decision=skip_lan_origin`），不再出现"局域网存档被挂到公共大厅"的问题；`lobby` 存档保持原有自动恢复房间行为。
- 旧版本产生的存档绑定没有 `HostChannel` 字段，一律按 `lobby` 处理，行为与旧版完全一致；缺失、空值、未知值也安全回退为 `lobby`（未知值记 warning 日志）。
- 诊断日志新增 `bindingHostChannel` / `effectiveHostChannel` / 续局 `decision` 字段；"永久放弃多人存档"时同步清理对应绑定。

## LAN 续局身份码

- 纯 LAN 存档不再发布大厅后，同 LAN 队友通过**续局身份码**回到自己的槽位：房主在续局等待页点击"续局身份码"，把与角色/玩家名一一对应的单条 `STS2LANRESUME:` 码发给每位队友；队友在手动 LAN/IP 加入页粘贴到"旧存档续局身份码"框即可。
- 身份码按角色/玩家名单独对应，不要互换；一次粘贴多条会被拒绝，防止误占槽位。
- 新游戏与普通直连无需身份码：客户端使用安装级 LAN 身份，连接超时会用同一身份自动重试一次。
- 进入大厅时若剪贴板中含有 `STS2LANRESUME:` 码，会显示使用指引而不是静默忽略。

## 存档保护

- "永久放弃多人存档"执行前，会先把 `current_run_mp.save` 备份到 `user://sts2_lan_connect/save-backups/`；读取或备份失败则拒绝删除。
- 修复安装 BaseLib（及依赖它的角色/观战 MOD）后多人存档必现损坏的问题：MOD 加载顺序把本 MOD 排在 BaseLib 之前时，BaseLib 的存档守卫从未生效，LAN 存档被误改名为 `.corrupt`。守卫现在会在 BaseLib 程序集加载时自动补挂，并新增游戏侧兜底——只要存档能以任一 LAN 身份正常校验就拒绝改名毁档（日志 `save_manager: blocked corrupt-save rename`）。

## 局内聊天 HUD 化改造

- 扁平半透明 HUD 外壳取代金色描边面板，细控制条取代标题栏与频道 tab；消息为单行富文本（去气泡、去常驻时间戳）。
- 每位参与者拥有稳定可读的昵称配色；共享引用措辞动词化。
- 全部控件满足 44px 触达目标；指针模式自适应（触屏保留聊天气泡入口与发送按钮）。
- 收到新消息时局内聊天自动浮现；打开/切频道/收消息时视图稳定停在最新消息，"N 条新消息"按钮恢复工作。
- 修复受邀频道聊天与表情选择器不可用、回车发送被竞争输入钩子拦截、发送失败态触屏不可见等问题。

## Android 修复

- 修复安卓（无 Steam 平台）打开"加入好友"页面时，游戏本体自动向 `127.0.0.1:33771` 发起调试直连、必须等满 ENet 超时才能操作的问题；现在仅在显式传入 `fastmp` 命令行参数时保留该开发者行为。
- 存档完整性与加入页守卫补丁不再因检测到 RMP MOD 而被跳过。

## 兼容范围

- 客户端版本：`0.5.3`。
- 服务端版本：与 lobby-service `0.5.1` / `0.5.2` / `0.5.3` 均兼容，不要求服主升级；`HostChannel` 仅存于客户端本地配置，不改变任何服务端 API、中继/控制通道或心跳协议。
- 聊天与加入线协议不变，与 v0.5.1+ 客户端互通不受影响。
- 游戏加载目标：`0.107.1`、`0.109.0` 与 `0.109.1`；`0.108.0` 不在适配范围内。
- 旧版本已产生的纯 LAN 存档可能仍会被自动发布一次；新版本创建的 LAN 存档起稳定分流。

## 安装与回滚

1. 完整退出游戏。
2. 用 `v0.5.3` Release 中的客户端安装器安装完整 `sts2_lan_connect` 目录，不要混用旧 DLL、PCK 或 manifest。
3. 重启游戏，在主菜单确认只加载一个 STS2 LAN Connect。
4. 如需回滚，完整卸载 v0.5.3，再安装正式 v0.5.2 客户端包；不要覆盖或移动历史 Release 资产。

发布顺序：先合并并推送远程 `main`，再把客户端包上传到现有 `v0.5.3` GitHub Release，最后更新 Steam Workshop。

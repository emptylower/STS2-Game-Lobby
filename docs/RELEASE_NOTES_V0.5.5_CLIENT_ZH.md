# STS2 LAN Connect v0.5.5 客户端正式发布说明

> 状态：`0.5.5` 客户端正式版。客户端 manifest、程序集和发布包版本均为 `0.5.5`；lobby-service 协议没有变化，继续使用 `0.5.4`。

## 游戏版本兼容

- 同一客户端 DLL 可分别加载在游戏 `0.107.1`、`0.109.0`、`0.109.1` 与 `0.110.x`，不再需要针对新旧游戏 ABI 分发不同客户端。
- 游戏 `0.110.x` 将版本、ID 数据库哈希和 gameplay MOD 清单迁移到 `PeerVersionInfo`；客户端会在运行时识别新旧握手结构。
- 普通加入、读档加入和运行中重连都会按当前游戏 ABI 填充请求，避免新版房间因缺少版本信息而拒绝加入。
- 扩容序列化补丁从实际 `playersInLobby` 元素类型解析旧 `LobbyPlayer` 或新 `StartRunLobbyPlayer`。

## 安全边界

- 这里的兼容表示同一个 MOD 包可分别运行在多个游戏版本上，不表示不同游戏版本可以互联；同一房间内所有玩家仍必须使用完全相同的游戏版本。
- 同一房间的玩家应统一安装客户端 `0.5.5`，避免严格 MOD 版本检查拒绝加入。
- 六个扩容线协议补丁必须完整生效；发现未知游戏线协议时会整组回滚并停止 MOD 初始化，不会带着半套补丁进入联机。
- `0.5.4` 的 AI 审核交互，以及更早版本的续局身份码、存档保护、聊天 HUD 和 MOD 预检全部保留。

## 验证

- 玩家测试已通过，覆盖新版游戏的启动、建房与加入流程。
- 客户端完整自动化测试通过；lobby-service 交叉版本测试通过。
- 最终客户端包以最老支持的 `0.107.1` 程序集为编译基线，并执行两次独立确定性构建比较。
- Steam 启动验证确认 `0.110.x` 运行时识别 `StartRunLobbyPlayer`，六个序列化补丁全部生效且 MOD 完成初始化。

## 安装与回滚

1. 完整退出游戏。
2. 使用发布包中的安装脚本覆盖安装完整 `sts2_lan_connect` 目录，不能混用旧 DLL、PCK 或 manifest。
3. 通过 Steam 启动游戏，确认模组列表显示 `0.5.5`。
4. 回滚时完整移除 `0.5.5` 目录，再安装 `0.5.4` 发布包。

正式下载地址与 SHA-256 校验值见 GitHub Release `v0.5.5`。
